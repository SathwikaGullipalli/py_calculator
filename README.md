# Calcify - Simple Python Calculator

Calcify is a basic command-line calculator built using Python.  
It supports simple mathematical operations and allows users to evaluate expressions directly from the terminal.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid inputs
- Handles division by zero errors
- Continuous calculation until user exits

## Technologies Used

- Python
